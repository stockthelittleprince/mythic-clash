# 神話爭鋒 V2（視覺特效測試版）

本版可以直接放在 GitHub Pages。保留 V1 的角色與卡牌資料，新增：
- 開局隨機抽取 30 名角色之一；翻牌揭示動畫；保留角色圖鑑入口。
- 卡牌依類型呈現圖騰與不同視覺風格，傳說牌使用金色卡框。
- 出牌時顯示攻擊、治療、防禦、詛咒特效，角色技能有專屬提示動畫。
- 低動態偏好（reduced motion）支援。

**注意：本版是視覺特效測試版，不是規則完整版。** 目前部分高階牌與角色被動尚未完整實作；卡牌圖騰仍是 CSS/文字符號，不是正式插畫；30 張角色立繪尚待製作。建議先測試視覺與操作，再進行完整規則重構。

## 更新到 GitHub

1. 下載並解壓縮 ZIP。
2. 打開解壓縮後的 `mythic-clash-v2` 資料夾。
3. 在 GitHub 專案根目錄選 `Add file` → `Upload files`，把檔案拖進去；若提示同名檔案，選擇覆蓋。
4. Commit changes，等 Pages 自動更新。

如網頁仍是舊版，強制重新整理 Ctrl+F5。
