MYTHIC CLASH｜一次更新步驟

1. 解壓縮本 ZIP。
2. 解壓後最外層應直接看到：assets、index.html、data.js、game.js、style.css、README.md。
3. GitHub：進入 mythic-clash → Add file → Upload files。
4. 一次拖入 assets 資料夾，以及 index.html、data.js、game.js、style.css、README.md。
5. 如果 GitHub 顯示同名檔案，讓新版覆蓋舊版。
6. Commit changes。
7. 等 GitHub Pages 更新約 1–3 分鐘後重新整理網站。
